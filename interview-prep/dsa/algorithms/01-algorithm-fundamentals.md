# Fundamentals of Algorithms

## What Is an Algorithm?

An **algorithm** is a well-defined set of steps used to solve a particular problem.

### Example: Adding Two Numbers

**Problem:** Find the sum of two numbers.

**Algorithm:**

1. Start.
    
2. Take two numbers as input: `A` and `B`.
    
3. Calculate their sum: `Sum = A + B`.
    
4. Display the result.
    
5. Stop.
    

**Example Input:** `A = 5`, `B = 10`

**Output:** `15`

## Characteristics of an Algorithm

1. **Well-defined Inputs and Outputs:** An algorithm should have clearly defined inputs and produce expected outputs.
    
2. **Clarity and Unambiguity:** Each step should be clear, precise, and unambiguous.
    
3. **Language Independence:** An algorithm should be independent of any programming language.
    

## Why Learn Algorithms?

1. **Efficient Problem-Solving:** Learning algorithms helps us understand different techniques for solving problems efficiently.
    
2. **Multiple Approaches:** A single problem can be solved in multiple ways using different algorithms.
    
3. **Performance Trade-offs:** Every algorithm has its own trade-offs in terms of time and space efficiency.
