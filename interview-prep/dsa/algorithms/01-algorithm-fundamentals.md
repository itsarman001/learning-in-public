# Fundamentals of algorithm

## What is an algorithm

an **algorithm** is a set of well defined to solve a particular problem

## Characteristics

1. Well Defined input and outputs
2. Each step should be clear and unambiguous
3. an algorithm should be language independent 

## Why algorithms

1. learning algorithms translates to learning different techniques to efficiently solve those problems
2. One problem can be solved in many ways using different algorithms
3. Every algorithm comes with its own tradeoffs when it comes to performance
