# 📚 Personal Knowledge Base

This repository contains my personal knowledge base built with **Obsidian**.

A personal knowledge base documenting my journey as a developer.

This repository is where I document what I learn, explore new concepts, work through technical challenges, and build a deeper understanding of software development.

It includes learning notes, project documentation, interview preparation, and useful resources collected along the way. The goal is to maintain a record of my progress, reinforce concepts through writing, and make my learning accessible and reusable.

## Repository Structure

```text
learning-in-public/
├── projects/       # Documentation and learnings from personal projects
├── learning/       # Technical notes organized by subject
├── interview-prep/ # Interview preparation and revision notes
├── resources/      # Courses, references, and useful links
└── archive/        # Outdated or inactive notes
```

## Projects

Project directories contain documentation covering different aspects of development, including:

## How I Use This Repository

- Document concepts while learning rather than relying solely on passive consumption.
- Break down complex topics into smaller, understandable notes.
- Record practical experiments, decisions, and challenges.
- Revisit and refine existing notes as my understanding improves.
- Keep useful learning resources and references in one place.

## Philosophy

Learning is an ongoing process. Not every note will be complete, and not every topic will be mastered on the first attempt.

This repository is a work in progress, reflecting what I'm learning, building, and improving over time.
